# Dhruvkahanhai — Portfolio Website

A minimalist, high-impact photography portfolio modeled directly after **Franklin Yeep** (`franklinyeep.com`) with page structure and mood inspired by **Peter McKinnon**.

Designed specifically so you **do not need any web development experience** to use, customize, manage, or expand it.

---

## 🌟 What We Built For You

1. **Exact Franklin Yeep Visual Aesthetic**:
   - Pure obsidian black background (`#000000`).
   - Timeless editorial serif branding: **Dhruvkahanhai**.
   - Clean top navigation with delicate underline on the active tab.
   - 3-column balanced photo masonry layout with generous spacing.
   - Zero clutter, zero borders, zero distractions — 100% focused on photography.

2. **Peter McKinnon Inspired Pages**:
   - **People** (Portraits, emotional moments, including your uploaded portraits)
   - **Places** (Cinematic landscapes, moody fog, mountain peaks, neon city streets)
   - **Things** (Vintage cameras, classic car silhouettes, everyday carry details)
   - **Client** (Concert arena stage photography, wedding rituals, editorial campaigns)
   - **About** (Minimalist bio, portrait, clients list, gear specs, direct contact email)

3. **Drag & Drop Anywhere**:
   - Drag any `.jpg`, `.png`, or `.webp` file from any folder on your computer directly into the browser window — it adds the photo to that gallery immediately!
   - In Editor Mode, drag photos around to **reorder** them.

4. **Create Any Page Anytime**:
   - Want a new page for **"Concerts"**, **"Street"**, **"Automotive"**, or **"Journal"**?
   - Simply click **`+ New Page`**, type the title, and it is instantly created and added to your navigation menu!

5. **Visitor View vs. Editor Mode**:
   - In the bottom right corner, there is an **`Editor [OFF / ON]`** pill (or press `Shift + E`).
   - **OFF (Visitor View)**: Looks 100% like Franklin Yeep’s pristine public portfolio. No buttons, no admin controls.
   - **ON (Editor Mode)**: Reveals "+ Add Photo", "+ New Page", "Export Backup", delete buttons, and drag handles.

6. **Automatic Saving & 1-Click Backup**:
   - Everything you do is automatically saved in your browser (IndexedDB).
   - Click **`Export Backup`** anytime to download a backup file (`.json`) so your portfolio is safely stored on your computer.

## 🚀 How to Open and View Your Website

1. Navigate to your project folder:
   ```
   C:\Users\dhruv\.gemini\antigravity\scratch\dhruvkahanhai-portfolio\
   ```
2. Double-click `Open-Portfolio.bat` (or double-click `index.html`).
3. It will open immediately in your web browser (Chrome, Edge, Brave, etc.)!

## 🌐 How to Put It Online for Free (In 60 Seconds)

When you're ready to share your portfolio with the world:

### Option A: Netlify Drop (Easiest — No coding at all)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the whole `dhruvkahanhai-portfolio` folder right into the browser window.
3. You will immediately get a live public link (e.g. `dhruvkahanhai.netlify.app`)!

### Option B: GitHub Pages / Vercel
- You can push this folder to a GitHub repository and turn on GitHub Pages, or connect it to Vercel for custom domain support (`dhruvkahanhai.com`).
